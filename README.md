# Precise Switch

**A lightweight keyboard layout switcher for Windows.**

Precise Switch helps you switch between keyboard layouts using configurable keyboard shortcuts. The application runs in the system tray and provides a settings window for configuration.

## Features

- Keyboard layout switching using customizable shortcuts.
- System tray integration.
- Multilingual interface:
  - English
  - Русский
  - Deutsch
  - Français
  - Español
  - Polski
  - Українська
  - Беларуская
  - 日本語

## Installation

1. Download the latest installer.
2. Run the installer.
3. Follow the installation instructions.
4. Launch Precise Switch.

Running as Administrator

Precise Switch normally runs without administrator privileges.
If you need to switch keyboard layouts in applications running with elevated privileges, you may need to run Precise Switch as Administrator as well.
To do so:
Close Precise Switch.
Right-click Precise Switch.exe.
Select Run as administrator.
Confirm the Windows User Account Control (UAC) prompt.
